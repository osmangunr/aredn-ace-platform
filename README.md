# AREDN ACE Platform

AREDN ACE Platform (Advanced Control Environment), AREDN ağlarını merkezi olarak yönetmek için geliştirilen açık kaynaklı ve Docker tabanlı bir yönetim platformudur.

## Hedef Modüller

- ACE Core
- Dashboard
- REST API
- AREDN Monitor
- Node Manager
- Harita
- RF Topology
- OTA Manager
- Telegram Bot
- Plugin System

## Teknolojiler

- TypeScript
- Fastify
- React
- PostgreSQL
- Redis
- Docker
- Nginx
